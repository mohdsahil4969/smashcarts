# SmashCarts — Game Design Brief

An original cartoon 3D kart-battle game for Android.

## Visual direction
Detailed cartoon 3D with readable silhouettes, saturated but controlled materials, expressive kart designs, clear weapon effects and mobile-friendly lighting.

## Match target
8 players per match. This is a product target, not yet implemented.

## Performance target
60 FPS target; 30 FPS fallback on lower-end devices. Performance must be measured on real Android devices before release claims.

## Core loop (planned)
Join match → drive around arena → collect weapon → attack opponents → earn score → match ends → receive progression rewards.

## Phase 1 scope
A reliable local driving prototype in a simple original arena. No multiplayer or combat in this phase.
